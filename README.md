# ⭐ StarsAPI — Sistema de Curtidas para Portfólio

API REST desenvolvida para gerenciar um contador de **estrelas** (curtidas) em tempo real para o meu portfólio pessoal. Construída com foco em escalabilidade e segurança, seguindo as melhores práticas de desenvolvimento Back-end.

---

## 🚀 Tecnologias Utilizadas

| Tecnologia        | Descrição                                     |
| ----------------- | --------------------------------------------- |
| **Node.js**       | Ambiente de execução JavaScript no servidor   |
| **Express**       | Framework minimalista para rotas e middleware |
| **MongoDB Atlas** | Banco de dados NoSQL em nuvem                 |
| **Mongoose**      | Modelagem de objetos e conexão com o MongoDB  |
| **CORS**          | Middleware para requisições entre domínios    |
| **Dotenv**        | Gerenciamento seguro de variáveis de ambiente |

---

## 🛠️ Funcionalidades

- **Leitura de Dados (GET)** — Busca o número total de estrelas armazenado no banco de dados.
- **Incremento de Dados (POST)** — Adiciona uma nova estrela ao contador oficial.
